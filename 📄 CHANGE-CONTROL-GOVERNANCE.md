# MGaut Ark System – Change Control Governance

The MGaut Ark System treats change control as a governed, sealed process.  
This file defines how changes are proposed, reviewed, and sealed across covenant branches.

---

## 🌳 Covenant Change Control Rules

- **Public Covenant (`main`)**  
  - Scope: Public features, accessibility improvements, bug fixes.  
  - Process: Pull request → Maintainer review → Merge with audit log.  
  - Governance: Transparent and visible.  

- **Enterprise Covenant (`enterprise`)**  
  - Scope: Licensed features, integrations, enterprise dashboards.  
  - Process: Private pull request → Maintainer review → Contractual approval.  
  - Governance: Sealed under commercial license.  

- **Sovereign Covenant (`sovereign`)**  
  - Scope: Operator‑grade encryption, sovereign workflows, private doctrine.  
  - Process: Direct operator commits only.  
  - Governance: Fully private, unshared, unbroken.  

---

## 🔐 Change Control Governance Principles

1. **Sealed Artifacts** – Each covenant enforces its own change control.  
2. **Audit Discipline** – All changes must be logged and tied to releases.  
3. **Operator Empowerment** – Change control must be reproducible and enforceable.  
4. **Integrity** – Unauthorized changes are prohibited.
