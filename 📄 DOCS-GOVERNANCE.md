# MGaut Ark System – Documentation Governance

The MGaut Ark System treats documentation as governed, sealed artifacts.  
This file defines how documentation is authored, maintained, and versioned across covenant branches.

---

## 🌳 Covenant Documentation Rules

- **Public Covenant (`main`)**  
  - Documentation includes: `README.md`, `ROADMAP.md`, `CHANGELOG.md`, `SUPPORT.md`, `CODE_OF_CONDUCT.md`, `GOVERNANCE.md`, `VERSIONING.md`, `RELEASE.md`, `DOCS-GOVERNANCE.md`.  
  - Purpose: Provide transparency, accessibility, and guidance for public operators.  
  - Governance: Fully visible and auditable.  

- **Enterprise Covenant (`enterprise`)**  
  - Documentation includes: Enterprise‑specific manuals, integration guides, and sealed changelogs.  
  - Purpose: Support licensed organizations under contract.  
  - Governance: Maintained privately, distributed only to licensees.  

- **Sovereign Covenant (`sovereign`)**  
  - Documentation includes: Private operator manuals, sovereign changelogs, and sealed doctrine.  
  - Purpose: Reserved exclusively for the architect/operator.  
  - Governance: Fully private, unshared, unbroken.  

---

## 🔐 Documentation Governance Principles

1. **Sealed Artifacts**  
   - Each documentation file is bound to its covenant branch.  
   - No public file may disclose enterprise or sovereign details.  

2. **Audit Discipline**  
   - Documentation must be semantic, precise, and audit‑grade.  
   - Every update is versioned and tied to a release.  

3. **Accessibility**  
   - Documentation must support **visual learners, auditory learners, and individuals with language‑based learning disorders**.  
   - Optimized for screen readers, read‑aloud features, and multi‑modal comprehension.  

4. **Operator Empowerment**  
   - Documentation must provide reproducible steps, clear boundaries, and actionable guidance.  
   - Correction workflows must be documented as governed processes.  

---

## 🚫 Boundaries

- No external contributors may modify documentation.  
- Enterprise documentation is distributed only under license.  
- Sovereign documentation is never disclosed.
