# MGaut Ark System – Governance Artifacts Index

This folder contains governed, sealed artifacts that define the lifecycle, stewardship, and discipline of the MGaut Ark System.  
Each file encodes a specific dimension of covenant governance.

---

## 📚 Index of Artifacts

- `GOVERNANCE.md` → Covenant model and lifecycle rules  
- `ROADMAP.md` → Directional boundaries and milestones  
- `CHANGELOG.md` → Release history (public covenant only)  
- `VERSIONING.md` → Semantic versioning and suffix discipline  
- `RELEASE.md` → Operator checklist for cutting releases  
- `SUPPORT.md` → Support boundaries (public, enterprise, sovereign)  
- `MAINTAINERS.md` → Stewardship and authority chain  
- `CODEOWNERS` → GitHub enforcement of stewardship  
- `WORKFLOW-GOVERNANCE.md` → Governance of GitHub Actions workflows  
- `DOCS-GOVERNANCE.md` → Governance of documentation lifecycle  
- `TESTING-GOVERNANCE.md` → Governance of testing and validation  
- `SECOPS-GOVERNANCE.md` → Governance of security operations  
- `RISK-GOVERNANCE.md` → Governance of risk identification and mitigation  
- `COMPLIANCE-GOVERNANCE.md` → Governance of standards and ethics  
- `RESILIENCE-GOVERNANCE.md` → Governance of redundancy, fallback, and continuity  
- `BACKUP-GOVERNANCE.md` → Governance of backups and restoration  
- `MONITORING-GOVERNANCE.md` → Governance of observability and metrics  
- `ESCALATION-GOVERNANCE.md` → Governance of incident escalation paths  

---

## ⚡ Operator Notes

This folder is itself a governed artifact.  
It ensures that governance is centralized, auditable, and covenant‑aligned.
