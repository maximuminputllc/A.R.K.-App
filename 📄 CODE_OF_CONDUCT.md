# MGaut Ark System – Code of Conduct

The MGaut Ark System is governed by a covenant model of discipline, stewardship, and accessibility.  
This project is not an open‑source collaboration. It is a sealed, proprietary system with defined covenants:

- **Public Covenant (`main`)** – Free, skimmed‑down version available to all.  
- **Commercial Covenant (`enterprise`)** – Licensed deployments for organizations.  
- **Sovereign Covenant (`sovereign`)** – Reserved exclusively for the architect/operator.  

---

## 🎯 Purpose

This Code of Conduct defines the standards of interaction for those who engage with the **public covenant**.  
It ensures that all communication remains respectful, professional, and aligned with the system’s governance philosophy.

---

## ✅ Expected Behavior

- Treat all operators, users, and maintainers with respect.  
- Report issues factually, with reproducible steps and clear context.  
- Use precise, audit‑grade language in all submissions.  
- Recognize that accessibility is a first‑class principle: the system is designed for **visual learners, auditory learners, and individuals with language‑based learning disorders**.  

---

## 🚫 Unacceptable Behavior

- Attempting to contribute code or pull requests (this project does not accept external contributions).  
- Demanding access to proprietary, enterprise, or sovereign branches.  
- Disrespectful, abusive, or dismissive communication.  
- Attempts to reverse engineer, decompile, or bypass licensing restrictions.  

---

## 🔐 Scope

- This Code of Conduct applies to all interactions in the **public covenant** (`main` branch), including issue reporting and discussions.  
- The **enterprise covenant** is governed by commercial agreements.  
- The **sovereign covenant** is private and not subject to external interaction.  

---

## 📬 Enforcement

- Violations may result in removal of access to issue tracking or other public covenant resources.  
- Enterprise violations are handled under contract terms.  
- Sovereign covenant violations are not applicable, as no external access is permitted.
