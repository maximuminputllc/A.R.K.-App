# AI-Assisted Research Kit App (A.R.K.)
# MGaut Ark System

**MGaut Ark** is a modular, standards‑grade application designed with layered governance, accessibility, and operator empowerment at its core.  
It has been intentionally engineered to support **visual learners, auditory learners, and individuals with language‑based learning disorders**, ensuring that every operator can engage with the system through multiple modes of interaction.  

---

## 🌳 Branch Structure

- **`main`** → Public Covenant  
  - Free, skimmed‑down version available to all.  
  - Hosted openly via GitHub Pages.  
  - Provides core study tools, playlists, and accessible UI.  
  - Licensed for use, but source code remains proprietary.

- **`enterprise`** → Commercial Covenant  
  - Available only to paying businesses and organizations.  
  - Adds enterprise dashboards, research integrations, and extended services.  
  - Deployed privately (Netlify/Vercel or equivalent).  
  - Governed by commercial licensing terms.

- **`sovereign`** → Private Covenant  
  - Reserved exclusively for the architect/operator.  
  - Contains full MGaut sovereign encryption and advanced operator‑only features.  
  - Never deployed publicly.  
  - Exists as a sealed, personal build.

---

## 🔐 Governance Philosophy

Each branch is treated as a **sealed artifact**:
- **Public covenant** → demonstrates capability without exposing proprietary architecture.  
- **Commercial covenant** → delivers value to organizations under license.  
- **Sovereign covenant** → remains private, unshared, and unbroken.  

This separation ensures clarity of purpose, auditability, and protection of intellectual property.

---

## 🚀 Deployment Pipelines

- **`main`** → Auto‑deploys to GitHub Pages (public URL).  
- **`enterprise`** → Auto‑deploys to private host (Netlify/Vercel) using GitHub Secrets.  
- **`sovereign`** → Builds only, no deployment.
