# MGaut Ark System – Maintainers

The MGaut Ark System is governed by a three‑covenant model.  
This document defines the stewardship and maintenance responsibilities for each covenant branch.

---

## 🌳 Public Covenant (`main`)

- **Maintainer**: Maximum Input, LLC  
- **Role**:  
  - Oversees the public covenant deployment via GitHub Pages.  
  - Reviews and responds to public covenant issues.  
  - Ensures accessibility standards are met for visual learners, auditory learners, and individuals with language‑based learning disorders.  
  - Maintains `CHANGELOG.md`, `ROADMAP.md`, and other public documentation.  

---

## 🏢 Enterprise Covenant (`enterprise`)

- **Maintainer**: Maximum Input, LLC  
- **Role**:  
  - Oversees enterprise covenant deployments to private hosts (Netlify/Vercel).  
  - Provides support and updates under commercial license agreements.  
  - Maintains sealed enterprise changelog and roadmap.  
  - Ensures contractual obligations for enterprise clients are met.  

---

## 🔐 Sovereign Covenant (`sovereign`)

- **Maintainer**: Architect/Operator (Maximum Input, LLC)  
- **Role**:  
  - Sole steward of the sovereign covenant.  
  - Maintains private changelog and roadmap.  
  - Oversees sovereign encryption, advanced operator features, and sealed artifacts.  
  - No external access, no delegation, no disclosure.
