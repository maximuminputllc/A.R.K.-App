# Contributing to MGaut Ark System

Thank you for your interest in the MGaut Ark System.  
This repository is not an open‑source project and does not accept external code contributions.

---

## 🔐 Governance Model

The MGaut Ark System is structured into three sealed covenants:

- **`main`** → Public Covenant  
  - Free, skimmed‑down version available to all.  
  - Deployed via GitHub Pages.  
  - Provided for demonstration and limited use only.  

- **`enterprise`** → Commercial Covenant  
  - Available only to licensed organizations under contract.  
  - Extended features, dashboards, and integrations.  

- **`sovereign`** → Private Covenant  
  - Reserved exclusively for the architect/operator.  
  - Not shared, not licensed, not open for contribution.  

---

## 🚫 External Contributions

- Pull requests from external parties will not be reviewed or merged.  
- Issues may be used to report bugs or request features in the **public covenant** only.  
- Proprietary code, encryption, and architecture are not open for collaboration.  

---

## 📜 Licensing

- The **public covenant** (`main`) is provided under a restrictive license: free to use in deployed form, but not to copy, modify, or redistribute.  
- The **enterprise covenant** (`enterprise`) is governed by commercial agreements.  
- The **sovereign covenant** (`sovereign`) is private and not licensed for any external use.
